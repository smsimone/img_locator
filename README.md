# img_locator

Semplice web app statica per trovare la posizione probabile di un'immagine target dentro una reference (es. pezzi di puzzle).

## Uso

1. Apri `index.html` (in locale o su GitHub Pages).
2. Carica l'immagine reference da file **oppure** inserisci un URL remoto e premi **Carica URL**.
3. Carica un'immagine target.
4. L'app mostra un cerchio rosso sulla reference nella posizione stimata del target.

## Note

- Stack minimale: HTML, CSS, JavaScript, jQuery.
- Il caricamento reference via URL richiede che il server remoto consenta CORS.
